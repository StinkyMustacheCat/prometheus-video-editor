# Parche 0.4.5.2

Aplica después de 0.4.5.1. Selecciona un clip visual y usa «Añadir LUT (.cube)» en el Inspector. Puedes elegir `assets/luts/neutral.cube`: la imagen debe verse igual antes y después. Prueba otro LUT de color, desactívalo, vuelve a activarlo y exporta un montaje corto. Guarda y reabre para confirmar que el efecto sigue asociado al clip. Selecciona dos clips visuales para probar la aplicación conjunta.
