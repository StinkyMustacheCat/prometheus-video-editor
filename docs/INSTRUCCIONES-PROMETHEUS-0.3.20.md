# Prometheus 0.3.20 — exportación

Cierra Prometheus y descomprime este parche sobre la carpeta que ya tiene 0.3.19. Acepta reemplazar archivos. La entrega necesita la versión completa 0.3.16.7 y todos los parches incrementales hasta 0.3.19.

El botón Exportar abre una ventana con formato MP4 o WAV, destino, resolución, FPS y calidad. El apartado Avanzado permite ajustar CRF o bitrate objetivo, velocidad de codificación, dimensiones y bitrate de audio. Las resoluciones conservan la proporción del lienzo; cambia el lienzo en Ajustes si quieres otro formato.

Antes del render hay una comprobación de medios. La exportación normal resuelve completos los medios web pendientes. La casilla de vistas ligeras crea un MP4 de revisión usando las representaciones locales disponibles sin descargar el original. Si falta una vista ligera, la comprobación lo indica. La descarga selectiva por rangos queda fuera de este flujo.

Prueba la exportación MP4 horizontal y vertical, el cambio de FPS, la salida WAV y la casilla de vistas ligeras con un medio web preparado. El progreso permanece visible durante la operación.
