# Prometheus 0.3.19 — lienzo y encuadre

Cierra Prometheus y descomprime este parche sobre la carpeta que ya tiene 0.3.18. Acepta reemplazar archivos. La entrega es incremental y necesita la versión completa 0.3.16.7 y todos los parches anteriores.

En Ajustes → Lienzo de la secuencia puedes elegir 16:9, 9:16, 1:1, 4:3 o dimensiones pares personalizadas. El monitor y la exportación usan el mismo lienzo; la secuencia conserva 60 FPS. Selecciona un clip visual para encontrar en Propiedades Encajar/Rellenar, escala y posición. Estos cambios conservan los cortes y son reversibles con Deshacer.

La ventana visible de Importar enlace se describe como importación de vídeo. El tratamiento interno de imágenes web para arrastrar desde navegador, pegado y recuperación permanece disponible.

Prueba un proyecto horizontal, cambia a 9:16, reproduce, mueve el encuadre de un clip y exporta un MP4. Guarda y reabre para comprobar que se conservan lienzo y encuadres; prueba Deshacer/Rehacer.
