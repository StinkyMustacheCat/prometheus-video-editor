# Parche 0.4.4

Extrae este ZIP sobre la carpeta descomprimida de Prometheus 0.4.3.1 y acepta reemplazar los archivos. No mezcles el parche con versiones anteriores.

Prueba: abre «Ver información del medio» desde la biblioteca y desde un clip; al abrir otro medio, la misma ventana debe cambiar de contenido. Comprueba copiar rutas o enlaces, abrir carpeta o página, cerrar con Esc y seguir editando con el Inspector. Cambia entre los diseños guardados y confirma que la ventana informativa nunca aparezca como panel acoplable.
