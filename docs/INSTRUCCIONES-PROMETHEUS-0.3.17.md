# Prometheus 0.3.17 — portapapeles contextual

Con Prometheus cerrado, descomprime sobre la carpeta con 0.3.16.7.2 y acepta reemplazar archivos. Es un parche incremental; necesita la entrega completa y los parches anteriores.

Ctrl+V pega clips copiados de Prometheus o importa archivos, imágenes copiadas y enlaces según el panel activo. Al pegar un enlace se abre Importar enlace para revisarlo antes de iniciar la descarga. Ajustes → Medios web permite activar explícitamente la importación directa y controlar la preparación automática de vistas ligeras de vídeo. Los audios web siguen resolviéndose de inmediato. El menú de huecos ya no muestra Añadir medio del proyecto.

Prueba: copia un clip y pégalo; después copia una URL y verifica que Ctrl+V abra el formulario con la URL. Pega una imagen del portapapeles y un archivo local en Medios y en la línea de tiempo. Pega texto normal en un campo de búsqueda y comprueba que se conserve la edición de texto.
