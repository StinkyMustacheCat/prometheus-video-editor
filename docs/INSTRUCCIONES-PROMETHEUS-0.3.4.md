# Prometheus 0.3.4 — parche incremental

Aplica los parches 0.3.1, 0.3.2 y 0.3.3 sobre la entrega completa 0.3.0. Después extrae este ZIP sobre la misma carpeta `Prometheus-0.3.0-win-x64`, con Prometheus cerrado y aceptando reemplazos.

En el botón **+** del panel Medios aparecen **Crear color sólido** y **Crear espacio reservado**. Indica un nombre y una duración en HH:MM:SS:FF (60 FPS). El color sólido permite escoger el color; el espacio reservado permite una nota para describir lo que irá allí. Ambos aparecen en Medios y se pueden arrastrar a una pista visual, mover, dividir y recortar como un medio de imagen.

El monitor muestra el color sólido o una tarjeta de espacio reservado con nombre y nota. Ambos se guardan dentro del proyecto sin depender de un archivo externo. El color sólido se exporta. Si queda un espacio reservado activo, la exportación de vídeo se detiene con un mensaje claro para evitar un resultado incompleto.

Prueba sugerida: crea un color sólido y un espacio reservado de distinta duración; arrástralos a V1, córtalos y guarda/reabre el proyecto. Comprueba la tarjeta en el monitor y exporta primero el color sólido. La conexión de archivos, imágenes y enlaces al espacio reservado llegará en 0.3.5.
