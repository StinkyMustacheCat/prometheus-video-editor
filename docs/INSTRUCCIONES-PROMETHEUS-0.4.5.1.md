# Parche 0.4.5.1

Aplica después de 0.4.4, sobre la carpeta original de Prometheus 0.4.3.1. Esta entrega cambia el esquema de guardado, pero aún no añade controles de efectos. Para probarla, abre un proyecto guardado en 0.4.4, modifica un clip, guarda y vuelve a abrir. El montaje y sus medios deben mantenerse.
