# Instrucciones y acciones de editor en 0.5.8

El documento de instrucciones sigue usando `format: "prometheus-instructions"`, `version: 1`, `project_id`, `revision` y `actions`. Pegar un documento carga tarjetas; la revisión comprueba cada tarjeta sin modificar el proyecto. Aplicar produce un solo paso de deshacer. Las tarjetas verdes son válidas, las amarillas requieren atención y las rojas no se aplican.

La acción nueva `media.import_shelf` recibe `shelf_id`, que se encuentra en `shelf_items` al usar **Copiar estado**. Opcionalmente acepta `sequence_id`, `track_id`, `at_seconds`, `placement` (`empty`, `overwrite` o `insert`) y `result`. Sin `track_id` guarda el medio en Medios. Con pista coloca el asset usando el tramo configurado en Bandeja. La revisión verifica que el elemento siga allí y que la pista sea compatible. Al aplicar, el elemento sale de Bandeja. Si ya hay un medio del mismo origen en el proyecto, reutiliza ese medio. La tarjeta también puede crearse arrastrando el elemento al panel Instrucciones o desde **clic derecho → Añadir desde Bandeja**. Al seleccionar la tarjeta, **Editar instrucción** permite cambiar el elemento y el destino visualmente; **Editar JSON avanzado** conserva acceso a todos los campos del contrato.

Las acciones de transporte y navegación son un contrato distinto de las instrucciones que modifican el proyecto. `EditorActionCatalog058.cs` define identificadores y argumentos tipados para reproducir, pausar, alternar, ubicar el lector, avanzar fotogramas o segundos, ir a inicio o fin, saltar entre límites de clip, cortes contiguos y marcadores, seleccionar clips o vinculados, y consultar tiempo, clip y secuencia. `EditorActionUi058.cs` ejecuta esas acciones sin cambiar la revisión ni crear pasos de deshacer. La entrada de voz se añadirá más adelante mediante este contrato; no se analiza texto libre en esta versión.

Los atajos existentes de reproducción, fotogramas, límites de clip y marcadores pasan por el despachador de acciones. `playhead.boundary` contempla comienzos y finales de clips; `playhead.junction` distingue cortes entre clips contiguos de una misma pista. Los comandos de edición destructiva permanecen en el flujo de revisión de Instrucciones.
