# Seguridad y privacidad

No adjuntes cookies, tokens, sesiones del navegador ni proyectos privados a una incidencia pública. Sustituye rutas personales y elimina metadatos sensibles de los informes.

El MCP es local y restringido al usuario de Windows. No lo expongas mediante un proxy público ni ejecutes plantillas MGT o instrucciones de edición de procedencia desconocida.

Si encuentras un problema sensible, utiliza un aviso privado de seguridad del repositorio si está habilitado. No publiques una prueba que incluya credenciales. Este archivo no afirma que exista un servicio de respuesta o un plazo de corrección garantizado.
